# Frontend Stack Decision

## 选定栈
- JS 框架: React 19

## 被否决备选
- Vue 3 — 理由: Existing dashboard codebase is fully written in React 19. Switching or mixing Vue would require complete rewrite and build tooling changes.
- Vanilla JS — 理由: Plain JS would make state synchronization and modal overlay rendering more verbose and error-prone.
