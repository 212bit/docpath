Risks and mitigations for R-216. The merge driver can lose user edits if it silently picks one side in an ambiguous conflict, so the default policy must fail loud on same-key or same-region divergent edits. Git integration writes local repository config and .gitattributes, so install must be idempotent, preserve existing unrelated attributes, and skip cleanly outside git repositories. Shell command registration in git config must use a stable command that works for installed shims and local development builds. The command should not run arbitrary user-provided shell fragments; it only receives file paths from Git and treats file contents as data. Backlog and rules formats may evolve, so parser behavior should be narrow and covered by fixtures rather than a broad markdown merger that appears more capable than it is. Because this touches agent workflow infrastructure, verification should include targeted merge-driver tests, install tests, build:test, node tests for the new test file, and docpath check before closeout.
