# 规约: 项目总览仪表盘与侧边栏布局

**任务 ID**: T-20260610-mgmt-ui-layout
**状态**: 已确认

## 1. 背景与动机

DocPath 工作流引擎拥有完整的项目/任务/检查/审查体系，但缺乏直观的可视化管理界面。本任务是 DocPath Management System 的起点，搭建整个管理后台的布局骨架和首屏仪表盘。通过 Dogfood 方式，管理后台直接读取 .docpath/ 文件数据，调 CLI 执行写操作。

## 2. 需求清单

### 功能需求
- [ ] FR-1: 侧边栏导航系统 - 固定左侧导航栏，包含所有管理模块入口（仪表盘/项目管理/Checks/Reviews/Backlog/设置），高亮当前激活项
- [ ] FR-2: 顶部导航栏 - 显示当前页面标题、DocPath 版本号、全局状态指示器
- [ ] FR-3: 项目总览仪表盘 - 作为首页，展示跨项目统计卡片（总项目数/活跃任务/通过率/阻塞项）
- [ ] FR-4: 响应式布局 - 移动端（<768px）侧边栏折叠为汉堡菜单，桌面端保持展开
- [ ] FR-5: 页面路由系统 - 使用 React Router，支持各模块页面导航及 URL 同步

### 非功能需求
- [ ] NFR-1: 技术栈 - React 18 + TypeScript + Vite + React Router v6
- [ ] NFR-2: 数据源 - 直接读取 .docpath/ 目录下的 JSON/MD 文件，不引入后端服务
- [ ] NFR-3: 构建 - 集成到 package.json scripts，`npm run build:dashboard` 构建 UI

## 3. 范围界定

### 包含
- 侧边栏布局组件（可复用架子）
- 顶部导航栏
- 仪表盘统计卡片
- React Router 路由配置（含各模块占位页）
- 响应式 CSS 方案（Tailwind 或 CSS Modules）
- 读取 .docpath/ 文件的数据工具函数

### 不包含
- 具体管理页面的完整 CRUD（后续模块实现）
- 实时 WebSocket 推送
- 用户认证/权限管理

## 4. 关键决策

| # | 决策 | 选项 | 结论 | 理由 |
|---|------|------|------|------|
| 1 | 样式方案 | Tailwind / CSS Modules / styled-components | CSS Modules | 无额外依赖，与已有项目一致 |
| 2 | 构建工具 | Vite / Webpack | Vite | 已有 tsup 用于 CLI，Vite 适合 UI |
| 3 | 数据读取 | 直接读文件 / 调 CLI / IPC | 直接读文件 | 简单直接，适合 dogfood；写操作调 CLI |
