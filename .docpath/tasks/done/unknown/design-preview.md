# Design Preview — 项目总览仪表盘与侧边栏布局

## 布局结构

```
┌──────────────────────────────────────────────┐
│  Header: 页面标题 | .docpath 版本号          │
├──────────┬───────────────────────────────────┤
│          │  Breadcrumb / 导航路径            │
│ Sidebar  ├───────────────────────────────────┤
│          │                                   │
│ 📊 总览  │  Content Area                     │
│ 📁 项目  │  (路由渲染各页面)                  │
│ ✅ 检查  │                                   │
│ 👁 审查  │                                   │
│ 📋 待办  │                                   │
│ ⚙ 设置  │                                   │
│          │                                   │
│ DocPath  │                                   │
│ v0.1.1   │                                   │
└──────────┴───────────────────────────────────┘
```

## 页面设计

### 总览仪表盘 (DashboardPage)
- 顶部: 4 个统计卡片（总项目数、活跃任务、检查通过率、阻塞项）
- 中部: 任务状态表格（ID、标题、阶段、状态标签）
- 底部: 最近活动列表

### 组件设计
- **Sidebar**: 深色背景 (#1a1d29)，260px 固定宽度，导航项悬停高亮，底部版本号
- **Header**: 浅色背景，页面标题 + 当前路径显示
- **Responsive**: <768px 侧边栏折叠为汉堡菜单

## 颜色方案
- Sidebar: #1a1d29 bg, #a1a7b9 text, #ffffff active
- Header: #ffffff bg, #1a1d29 text
- Content: #f5f7fa bg
- Primary: #4f6ef7
- Success: #22c55e
- Warning: #f59e0b
- Error: #ef4444
