# Workflow: Research

> 调研/探索任务

## 阶段

### 1. Define (定义问题)
- 明确调研目标
- 产出问题清单

### 2. Explore (探索)
```bash
docpath journal "调研发现"
```
- 收集资料、尝试方案
- 持续记录 journal

### 3. Synthesize (综合)
- 整理结论
- 推荐方案

### 4. Report
- 产出: 调研报告（写入 .docpath/tasks/<id>/ 任务目录，随 journal 归档）

### 5. Done
```bash
docpath done
```
