## 背景

spec.json 和 plan.json 各自有一个 markdown 字段，内容与同目录 spec.md/plan.md 完全相同（100% 重合，已验证）。write-spec/write-plan 命令写入时双向维护，单次失败产生静默不一致；JSON 体积因此翻倍（spec.json 9.2KB vs spec.md 3.9KB）。修复方向：JSON 移除 markdown 字段，spec.md/plan.md 变为单一真相源。需要检查哪些代码路径读取了 JSON 的 markdown 字段。

## 验收

1. write-spec/write-plan 不再向 JSON 写 markdown 字段\n2. 所有读取 spec.json/plan.json 的代码不依赖 markdown 字段\n3. 旧 JSON 有 markdown 字段时读取不报错（向后兼容忽略）\n4. spec.json 体积降至纯结构化字段大小\n5. pnpm test 全量绿
