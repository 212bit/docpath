## 背景

Second-pass dogfooding after the workflow DX task exposed remaining operator friction: review warnings still mix current-diff issues with existing file-level/baseline warnings; closeout still emphasizes manual git add -f even though docpath commit --stage can now consume canonical evidence; docpath done journal output is verbose and prompt-like for normal closeout. These issues do not block correctness, but they keep the workflow noisy and force the operator to interpret low-signal output.

## 验收

Acceptance: (1) review output/evidence distinguishes findings that overlap current diff lines from existing file-level findings where practical; (2) review summary makes current-diff vs baseline/whole-file warning counts visible; (3) changes/closeout guidance recommends docpath commit --stage when canonical ignored evidence is present and still exposes exact git add -f fallback; (4) done/journal closeout output is less prompt-noisy where practical without removing task evidence; (5) focused tests cover the new review classification and closeout guidance; (6) pnpm test/typecheck and docpath check/review/done pass or residual issues are documented.
