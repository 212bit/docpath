## 背景

When task files drift, docpath check only supports single-direction overwrite which might lose changes. We should implement a smart three-way merge using git merge-file or text diffs to automatically resolve non-overlapping drifts and produce standard conflict markers when overlap exists.

## 验收

The check command is updated. In case of drift content-mismatch, running check attempts a three-way merge. Standard tests cover successful merging and graceful fallback to conflict markers on overlap.
