## 背景
[来源: codex session 挖掘 @ evoucher 2026-07] 一个会话内出现四类漂移反复告警 + agent 大量手动抢救：
- A. write-plan 后阶段回退到 planning（friction: "DocPath 阶段回退到了 planning"）。
- B1. `source.content_sha256 不一致`（plan.md 与 plan.json 内嵌哈希对不上）4 次。
- B2. `current/canonical 漂移`（current alias 与 canonical 目录文件内容不一致）5 次。
- B3. `Plan/Breadcrumb 漂移`（plan 标记完成但缺 breadcrumb）4 次。
- 手动操作: 55 次触及 plan.md/plan.json（sed 读 30+、shasum 比对 3、rg 哈希字段、git add 强提交对齐 20+），12 次 apply_patch 直接编辑 canonical/plan.md，而正经 `docpath write-plan` 仅 4 次。

## 代码核实 (2026-07-06，第二轮修正)
**A — 总根源，真 bug**:
- `src/commands/write-plan.ts:73` `transitionWorkflow(cwd, 'plan.ready', ...)` 无条件触发。
- `src/engine/transitions.ts:65` `plan.ready` 的 `from: ['idle','drafting','planning','executing']` 含 executing。
- 后果: executing 阶段重跑 write-plan 修计划 → 合法回退到 planning，丢失执行态。agent 因此不敢用 write-plan。

**B1 — sha256 漂移，A 的直接后果**:
- `src/utils/structured-docs.ts:175-181` `sourceForMarkdown` 写 plan.json 时用 `markdownSha256(markdown)` 算 content_sha256；`writeActiveTaskFile` (`task-files.ts:56-58`) 传同一份 content，write-plan 自身不会产生 sha256 漂移。
- 漂移来源: agent 用 `apply_patch` 直接编辑 canonical/plan.md（12 次），plan.md 变了但 plan.json 的 content_sha256 没重算 → `structured-docs.ts:744` 报 `source.content_sha256 不一致`。

**B2 — current/canonical 漂移，同源**:
- `writeActiveTaskFile` 原子写 canonical + current 两份，write-plan 自身不产生漂移。
- 漂移来源: agent apply_patch 只改 canonical/plan.md，没改 current/plan.md 别名 → `task-files.ts:344` content-mismatch。

**B3 — Plan/Breadcrumb 漂移**:
- plan 标记完成但缺对应 breadcrumb 步骤，属另一检查维度，但同根于 agent 绕过正常 step 流程手编 plan。

**结论**: A 是因，B1/B2/B3 是果。agent 绕过 write-plan 手编 plan.md，正是因为 A 让 write-plan 不可用（会丢执行态）。修 A 后，agent 回归 write-plan，三类漂移自愈大半。

## 关联
- 与 R-253（checklist 不同步）同链条: agent 用 apply_patch 勾 checklist，正是因为 `agent step --status done` 不同步 plan.md checklist（R-253）。R-253 修了，agent 就不必 apply_patch 勾选，B1/B2 进一步减少。

## 验收
- A: write-plan 在 phase=executing/checking 时不得回退到 planning；仅更新 plan.md/plan.json，保留当前 phase。回归: executing 阶段跑 write-plan，确认 phase 不变。
- A 备选: 提供 `docpath write-plan --no-transition` 仅写文件不动状态机。
- B1/B2: 修 A 后验证 sha256 与 current/canonical 漂移告警消失；额外建议 check 检测到 sha256 漂移时给出 `--fix-drift` 重算 plan.json 的修复提示。
- B3: 确认 step done / write-plan 同步写 breadcrumb，消除 plan/breadcrumb 漂移。
