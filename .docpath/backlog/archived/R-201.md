## 背景

Dogfood of docpath commit exposed ignored-but-tracked DocPath files. The current repo ignore rule ignores the whole /.docpath/ tree, which also marks canonical backlog and completed task evidence as ignored. Tighten ignore rules to runtime-only paths and add a diagnostic for tracked ignored runtime noise.

## 验收

AC1 .gitignore ignores DocPath runtime state and worktrees without ignoring canonical backlog/task evidence. AC2 A DocPath diagnostic reports tracked ignored runtime files with an explicit git rm --cached suggestion. AC3 Tests cover runtime-noise detection and keep canonical task evidence out of the noise set.
