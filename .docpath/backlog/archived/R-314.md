## 背景

DocPath 曾有 Web Dashboard（React/Vite UI），已于 commit 754d11b 整体删除，但清理不彻底，留下四处残留。这些是纯死代码，删除无任何行为变更。

现状核实（2026-08-30）：

1. `package.json:31` 仍声明 `"vite": "6.3.5"` 于 dependencies，而 `grep -rn "from ['\"]vite" src/` 零命中 —— vite 除了 dashboard UI 外在本项目无任何用途。
2. `@types/prompts` 错放在 dependencies（应为 devDependencies）。
3. `src/commands/register/aliases.ts` 注册 `s` / `st` / `c` 三个单字母别名，是给人类省敲键盘用的；Agent 调用一律走全名，68 行注册代码零收益。
4. `src/utils/ui-gate.ts:30` 的 UI 检测正则里仍保留 `dashboard` 关键词 —— dashboard 命令已不存在，该分支永远命中不了。
5. `src/commands/register/backlog-maintenance.ts:51` 的 `tasks` 命令是 R-299 引入的 deprecated 兼容转发，注释自述"保留一个版本周期"，周期已过。
