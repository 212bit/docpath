## 背景

Dogfood 暴露两个同源边界问题：reveal/context 的 topic docs 会把 docs.md、archive/docs-legacy 等生成或历史大索引纳入普通候选，导致 selected token 预算信号失真；completed/idle 无活跃任务时 analyze/write-analysis 仍可能复用上一 task_id，status/next 也可能被旧 breadcrumb 计数误导。

## 验收

topic docs 的候选和预算不再被生成视图主导；生成视图与历史大索引保持可发现但降权或标记；无活跃任务时 analyze/write-analysis fail-loud 或引导 capture/promote；idle 无 task_id 时 next 不推荐旧步骤；补齐测试、文档、check、review。
