## 背景

After adding read-only docpath doctor, the next optimization is an explicit cleanup mode for tracked ignored runtime noise. The command must mutate Git index only when the user opts in, and must only untrack the runtime whitelist already classified by git hygiene detection.

## 验收

AC1 doctor exposes an explicit cleanup flag for tracked ignored runtime noise. AC2 cleanup runs git rm --cached only for runtime-noise whitelist paths, not canonical backlog or done task evidence. AC3 dry/read-only doctor behavior remains unchanged by default. AC4 tests cover cleanup and canonical evidence preservation.
