## 背景
ExpertTeam-Codex 的 $expert-* 使用体验简单，适合 Codex CLI / Codex App；DocPath 当前已有 install health，但更偏协议文件安装。若能生成 Codex Skill 入口，可把 DocPath 状态机能力包装成低门槛专家团体验。

## 目标
新增 DocPath Codex Skill 适配器，生成 $docpath、$docpath-product、$docpath-design、$docpath-software 等入口，并在 Skill 内强制遵守 DocPath 状态机。

## 范围
- 生成 ~/.codex/skills 或项目级 .codex/skills 的 SKILL.md。
- Skill 文案包含：先 status/next，非平凡任务走 spec→plan→go→agent enter，完成后 check/review/journal。
- 可复用专家团角色与业务模板。
- 安装前检测已有文件，默认不覆盖；支持 dry-run 和 manifest。

## 验收
- docpath install --target codex 或等价命令可安装/验证 skill 文件。
- install health 能检测缺失、漂移、frontmatter name 错误。
- 不覆盖用户已有 Codex 配置，除非明确 --force。
- 文档包含 Codex CLI/App 调用示例。
