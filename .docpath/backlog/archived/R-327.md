## 背景

write-spec stdin 在同一已启动任务内重同步 spec 真源时不应重置 workflow phase。当前问题是相同 task_id 的 spec 同步会走 task created 转移，把 executing checking planning 误回到 drafting，并可能给出错误恢复提示。本次只处理同任务重同步和提示选择，不改变新任务创建行为。

## 验收

AC-1 同 task_id 重同步保持当前 phase。AC-2 非 blocked 状态不推荐 recover。AC-3 新任务和 completed 后新 spec 绑定保持兼容。AC-4 自动化测试覆盖以上行为。
