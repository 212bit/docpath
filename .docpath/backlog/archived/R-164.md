## 背景

R-163 已建立 schema-first JSON/JSONL 真源，但 spec.json 仍是第一版结构化外壳，主要包含 title、FR/NFR、AC、Decision Brief 和 markdown 原文。为了让 spec 真正成为 check/next/context-index/UI/重大变更门禁的机器契约，需要继续把 task/backlog linkage、scope、major_change_gate、ui_gate 和 source metadata 字段结构化，同时保持 spec.md 作为 CLI 渲染视图和旧任务兼容输入。

## 验收

1. spec.json 增加 task_id、backlog_id、title、source.created_at/source.updated_at 等基础元数据，并保留 schema_version。2. spec.json 增加 scope.included/scope.excluded 结构化字段，长文本允许 Markdown 字符串。3. spec.json 增加 major_change_gate.required/types/user_confirmed/decision_brief_markdown 字段，并让重大变更门禁优先读取这些字段。4. spec.json 增加 ui_gate.required|exempt|unknown 或等价结构字段，并让 UI 门禁优先读取结构化字段。5. spec.md 仍可由 spec.json 渲染，旧 spec.md 缺少 spec.json 时可迁移生成，损坏 spec.json 必须 fail loud。6. 增加覆盖 spec JSON 字段解析、门禁优先读 JSON、Markdown fallback、render 可重建和损坏 JSON fail loud 的测试。
