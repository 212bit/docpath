## 背景

Adopt the confirmed UI workflow: one high-density ui-brief.md is the canonical UI design source for image generation, wireframes, implementation, and review. Keep design-approval.md as a thin approval state artifact and visual-acceptance.md as thin post-implementation evidence. Do not require frontend-stack.md, design-preview.md, or external-design-handoff.md by default for UI gate pass.

## 验收

UI gate and docs require ui-brief.md plus approved design-approval.md before implementation; ui-brief template includes screen, flow, layout, components, states, visual, generation prompts, and acceptance contract; write-design template/all behavior reflects canonical plus thin files; design skill and protocol docs no longer present the old multi-file route as the default; focused tests pass.
