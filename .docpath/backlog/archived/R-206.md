## 背景

Dogfooding exposed that DocPath worktrees copied from a branch can miss .docpath/workspace runtime files. backlog promote then partially writes task/backlog artifacts before failing on workspace/state.lock, and init on an existing .docpath does not repair missing runtime views.

## 验收

backlog promote creates missing workspace runtime before state locking; lock acquisition creates the lock parent directory; init without --force repairs missing state/current/breadcrumb runtime files without overwriting existing config or rules; regression tests cover these paths.
