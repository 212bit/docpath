## 背景

Multiple concurrent worktrees modifying backlog.md or rules files cause frequent git line conflicts on merges. We need a custom Git merge driver that structurally resolves these conflicts.

## 验收

1. Add a CLI action docpath merge-driver to resolve three-way merges on backlog and rules files.\n2. Automatically register the merge driver in .git/config and map it for backlog and rules files during install.\n3. Add unit tests verifying conflict resolution.
