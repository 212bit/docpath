## 背景

In docpath CLI commands, many modules statically import child_process, yaml, and other heavy dependencies. For fast startup times and low resource usage during hot paths, we should rewrite these static imports to use dynamic runtime imports inside subcommand implementations.

## 验收

The command registers successfully, types compile with no emit errors, unit tests pass 100%, and check/agent-output commands load dependencies dynamically on-demand.
