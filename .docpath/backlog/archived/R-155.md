## 背景

当前 DocPath Markdown 总量已接近 95 万字节，历史任务归档、workspace 决策日志、模板、设计文档和规则文件处在同一可读取面中。Agent 若默认扫描 .docpath/docs/templates，会产生高 token 消耗，并放大 current/canonical、rules/spec、archive/index 之间的漂移风险。本需求将 DocPath 从‘文档都可被 Agent 读’升级为‘索引优先、当前任务优先、归档按需读取、规则高信号化’，保留长期记忆但压缩默认上下文。

## 验收

1. next/context/reveal 的默认输出只包含路由索引、当前任务包和必要规则摘要，不默认读取 tasks/done、templates、完整 docs 或大型 workspace 日志。 2. 项目级索引能记录文档 path/kind/scope/default_read/summary/token_estimate，并支持按 topic/task_id 展开。 3. rules 路径与 spec 路径职责清晰，长期规则只保留高信号约束、架构决策和真实避坑。 4. check 能发现默认上下文预算过大、当前任务缺 spec/plan、规则双真源或索引陈旧等漂移风险。 5. 历史归档仍可追溯，但必须通过索引按需读取。
