- 修正原描述: check **已经给出修复命令提示**（`docpath docs scan`），R-250 描述的"无自愈/重建路径"不准确。
- 真痛点:
  1. check 自己不重建 docs-index，要 agent 手动跑 `docpath docs scan`，流程断裂。
  2. 每次任务产物更新（breadcrumb/plan/spec）都会让 docs-index 陈旧，warning 高频复现（R-248 修复时又复现一次）。
  3. warning 与失败项混在 check 输出里，agent 容易忽略。

## 验收（最小修法，待定方向）
