## 背景

Dogfooding in DocPath worktrees exposed two workflow polish issues: existing-project init repairs runtime but exits nonzero when the project registry database is read-only; docpath check in a Git worktree fails to find tsc/tsup when node_modules exists only in the main checkout.

## 验收

Existing-project init treats registry write failures as a warning after successful runtime repair; docpath check can resolve tools from the main worktree node_modules/.bin when running inside a linked Git worktree; tests cover both behaviors.
