## 背景

docpath next --agent currently routes to docpath learn --dry-run whenever lesson_summary.pending_count is nonzero, even when learn would classify every candidate as skipped and produce no actionable rules. This creates a stale no-op recommendation after completed tasks.

## 验收

next should not recommend docpath learn --dry-run when all lesson candidates would be skipped by learn classification; learn summary and next routing should use a consistent actionable candidate definition; regression tests cover skipped-only candidates.
