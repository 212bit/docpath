## 背景

Dogfooding showed docpath worktree create deletes tracked .docpath/tasks, docs.md, and docs-index.json copies when configuring a new worktree. In projects where durable DocPath evidence is tracked, the new worktree starts dirty with mass deleted files, defeating the goal of isolated clean worktrees.

## 验收

docpath worktree create must leave a new worktree clean when .docpath/tasks and docs index files are tracked; tracked .docpath resources must be preserved as tracked copies; untracked runtime paths may still be initialized for isolation; regression tests and real dogfood validation must pass.
