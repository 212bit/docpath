## 背景

当前 decisions.jsonl 和 journal 只有文件存储，跨 session 查决策只能全文 grep。在 journal 写入时自动建立倒排关键词索引，让 docpath reveal --topic <keyword> 支持内容匹配而非仅文件名匹配。

## 验收

- `docpath docs scan` 为 Markdown 文档建立 compact 内容词索引，使正文关键词可被 topic 查询命中。
- `docpath reveal --topic <keyword>` 能命中正文中出现、但 path/title/summary 均未出现的关键词。
- `docpath context --topic <keyword>` 复用同一索引匹配语义，不回退到运行时全文 grep。
- 索引仍保持 compact：不写入全文正文，默认不输出 `topic_tags`，归档正文展开策略保持不变。
- 现有 topic synonym 行为保持不变。
