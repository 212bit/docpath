## 背景

Dogfooding showed docpath plan can write an incomplete plan that covers only the first functional requirement, while still advancing workflow state to planning. A generated plan must cover every FR/NFR/AC or fail before writing.

## 验收

docpath plan either writes a plan that covers all spec requirements and acceptance criteria, or refuses to persist/advance with actionable diagnostics; regression tests cover multi-FR specs and prevent partial generated plans.
