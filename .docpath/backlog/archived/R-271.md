## 背景

tracked backlog 被复制为 stale 快照。见 .docpath/backlog/analysis/R-271-analysis.md。强制 live-shared symlink + doctor FAIL。

## 验收

AC-1: worktree create 将 backlog 建为指向主仓的 symlink。AC-2: doctor 在 backlog 为普通目录副本时 FAIL。AC-3: --backlog 在 live-shared 下无需拷贝即可可见。AC-4: 自动化测试覆盖 create symlink 与 doctor fail。

## superseded-by R-273 (2026-07-16)

backlog → git 记为整目录删除 → `add -A` + 合并回 main 删除 main 的 backlog 并
留下悬空 symlink（R-273 已复现）。本条的 symlink 契约与 2026-06-30 用户确认的
R-238 Option B（backlog merge-mediated tracked）相悖，且实现时未引用 R-238。

merge-mediated tracked 副本；本条的 id 撞号动机改由 R-273 FR-3 的跨 checkout
id 单池分配器解决；stale 快照降级为已知限制。见
`.docpath/backlog/analysis/R-273-analysis.md` 与 ADR。
