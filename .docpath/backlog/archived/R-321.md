## 背景

ls .docpath/backlog 全是裸号 R-###.md(20/20),task 目录却带 slug,不一致。根因: createBacklogItem 用 wx 占号裸名,使 writeBacklogItem 的 slug 分支成死代码。另 5 个 done 未及时归档,默认列表混终态噪声。

## 验收

1) 新建条目文件名带标题 slug(策略见 spec Decision Brief),ls 即可辨识;2) 存量裸号仍按 id 前缀解析,不批量迁移;3) done 可靠归档,默认 list/index 不含终态噪声;4) 补测试覆盖 slug 生成+归档+裸号向后兼容。
