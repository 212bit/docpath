## 背景

Implement a command docpath worktree merge to automate merging a worktree's changes back to the main branch.

## 验收

The CLI command docpath worktree merge [branch] is added, checks isolation contracts, commits leftover files, merges from origin/main, and merges back to main/target using --no-ff.
