## 背景

Agent-facing DocPath commands still emit redundant normal-state diagnostics and large document index summaries. This increases token use during start/resume, check/changes closeout, context/reveal, and completed-state routing. The task should keep the workflow contract intact while reducing default output volume.

## 验收

Default agent outputs omit empty or healthy diagnostic details; document index summaries are compact by default and expand only with topic/task/verbose/full modes; low-value lesson candidates do not dominate completed-state routing; tests cover compact output and existing JSON/verbose compatibility.
