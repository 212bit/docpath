# DocPath UI Design - UI/UX Analysis

## 1. 信息架构与页面清单

### 页面层级
```
Dashboard (Root)
├── Overview (/)                    - 项目总览 + Attention Queue
├── Workboard (/workboard)          - 任务看板、步骤执行
├── Gates (/gates)                  - Check/Review 门禁详情
├── Events (/events)                - 事件时间线
├── Backlog (/backlog)              - 需求池管理
└── Worktrees (/worktrees)          - 工作树状态监控
```

### 导航模式
- **左侧边栏**：
  - 顶部品牌区：Logo + 可折叠按钮
  - 导航分组：Project 视图（4 个）、Workspace 视图（2 个）
  - 底部项目列表：滚动式项目选择器，带搜索和状态筛选
- **顶部 Header**：
  - 左侧：当前项目名称 + 路径
  - 右侧：Phase/Gate 徽章 + Refresh 按钮

## 3. 组件、状态、表单与校验

### 核心组件库
1. **Badge 徽章**
   - 变体：`pass`, `fail`, `warn`, `info`, `idle`, `accent`
   - 尺寸：`sm`（default）、`lg`
   - 状态：静态显示，无交互

2. **Button 按钮**
   - 变体：`primary`（terracotta）、`secondary`（outline）、`ghost`
   - 形状：圆角 `999px`（pill 形）
   - Hover：提升 2px + shadow

3. **Card 卡片**
   - 背景：`var(--color-surface)`
   - 边框：`1px solid var(--color-border)`
   - Hover：边框变为 `var(--color-border-hover)` + 轻微缩放

4. **Panel 面板**
   - 包含 `panel-heading`（标题 + 徽章）和 `panel-body`
   - 用于分组相关信息

5. **Table 表格**
   - 斑马纹行
   - Hover 高亮
   - 空态："No data available"

6. **Modal 对话框**
   - 背景遮罩：`rgba(0,0,0,0.6)`
   - 内容区：居中、最大宽度 600px
   - 用于命令执行日志

### 表单与校验
当前 Dashboard 无复杂表单，仅有：
- **搜索框**：项目过滤，实时筛选
- **状态筛选器**：按钮组，单选模式

### 交互状态
- **加载态**：Refresh 按钮旋转动画
- **成功态**：绿色徽章 + "✅" 图标
- **失败态**：红色徽章 + "❌" 图标
- **禁用态**：opacity 50% + cursor not-allowed

## 4. 空态/错误/加载/权限态

### 空态设计
| 场景 | 当前实现 | 优化建议 |
|------|----------|----------|
| 无项目 | "No projects" 文本 | 添加插图 + 引导文案："Run `docpath init` to get started" |
| 无事件 | "No events recorded" | 显示时钟图标 + "事件会在任务执行时自动记录" |
| 无 backlog | "No requirements" | 显示加号图标 + "Use `docpath backlog capture` to add requirements" |

### 错误态设计
- **API 失败**：顶部红色 banner，显示错误信息
- **项目不可用**：项目列表中显示灰色"unavailable"标签
- **门禁失败**：红色徽章 + 可展开的错误详情

### 加载态设计
- **初次加载**：骨架屏（Skeleton）显示主要布局
- **刷新**：按钮图标旋转，保留现有数据
- **命令执行**：Modal 中显示"RUNNING"徽章 + 脉冲动画

### 权限态设计
- 当前所有操作都通过 CLI 执行，Dashboard 仅显示只读数据
- 未来若引入写操作，需添加用户确认对话框

## 5. 响应式、可访问性与文案

### 响应式策略
- **宽屏（>1440px）**：左侧边栏 220px + 主内容区自适应
- **中等屏幕（1024-1440px）**：侧边栏可折叠到 56px
- **窄屏（<1024px）**：单列堆叠，侧边栏变为顶部抽屉

### 可访问性
- **键盘导航**：Tab 键依次聚焦，Enter 激活
- **语义化标签**：
  - `<nav>`：导航栏
  - `<main>`：主内容区
  - `<article>`：面板组
- **对比度**：
  - 背景 `#F7F4EF` vs 主文本 `#1F2421` = 10.8:1（AAA 级）
  - Terracotta `#C4612F` vs 背景 = 4.7:1（AA 级）
- **屏幕阅读器**：
  - 状态点用 `aria-label="active"` 标注
  - 加载中用 `aria-live="polite"` 播报

### 文案风格
- **标题**：简洁祈使句，如"Attention Queue"、"Quality Gates"
- **提示**：友好且具体，如"All projects healthy"（而非"OK"）
- **错误**：先说what，再说how，如"Check failed: 2 errors → docpath check --fix"
